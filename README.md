# Dashboard de Despendoamento

Dashboard executivo estático para acompanhamento de área realizada, horas trabalhadas, ativos e tipos de corte.

## Publicação

O projeto foi preparado para o GitHub Pages. O arquivo de entrada é `index.html` e não requer etapa de compilação.

## Atualização pelo Google Sheets

Para a atualização automática, a planilha deve permitir leitura para qualquer pessoa com o link. Caso contrário, use o modo privado disponível no próprio dashboard: copie o intervalo `A1:L1000` ou importe um CSV.
